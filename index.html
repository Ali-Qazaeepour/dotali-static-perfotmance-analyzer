    Core Web Vitals – Quick Guide

    • LCP: keep initially visible and hero images eager; optimize their size and format.
    • CLS: reserve space with correct image width/height or CSS aspect-ratio.
    • CSS weight: remove unused rules, keep critical CSS small.
    • Review stylesheet requests and duplicated styles; combining files is not always faster.
    • Use loading="lazy" only for images outside the initial viewport.
    • Preload critical, late-discovered assets only when measurements justify it.
    • This tool does not measure Core Web Vitals. Verify changes on the rendered page.
